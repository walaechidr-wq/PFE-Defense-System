# 🎓 PFE Defense Management System

**A Java Desktop Application for Managing End-of-Study Project Defenses**

## About the Project

PFE Defense Management System is a Java desktop application designed to simplify and automate the management of end-of-study project defenses within academic institutions.

The application provides a centralized platform for managing students, groups, professors, supervisors, jury members, and defense schedules.

## Features

- Student and Group Management
- Professor and Supervisor Management
- PFE Project Assignment
- Automated Defense Scheduling
- Jury and Room Management
- PDF and Excel Document Generation
- Dashboard and Statistics
- Planning History

## Technologies Used

- Java 17
- Java Swing
- Apache POI
- OpenPDF
- JFreeChart
